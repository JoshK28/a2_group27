# a2_group27

IAB207 Assignment 2: Flask event management web application (Group 27).

## Run locally

```
pip install -r requirements.txt
python main.py
```

Then open http://127.0.0.1:5000

## Workflow

- `main` always runs. Don't commit directly to it.
- One branch per board card, named `sprint2-<owner>-<task>`, for example `sprint2-josh-event-details`.
- Commit small and often, from your own GitHub account.
- Pull `main` before you start a branch; open a pull request to merge, and have the other person review it.
- Move your card on the project board (Backlog → Todo → Doing → Done) as you go.
